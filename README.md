# What is RaccNet Pocket?
RaccNet Pocket is an open-source social platform built on the AT Protocol, meaning you can easily log in using your Bluesky handle, and seamlessly swipe through your Bluesky feeds!
# Development
### Current State
RaccNet Pocket v2.0 is currently being worked on. This is a major overhaul of v1.0, adding a plethora of new features and overhauled UI. You can download the latest alpha build of 2.0 in the [Releases](https://github.com/RechoRaccoon/RaccNet-Pocket/releases) page.
### Long-Term Roadmap
v3.0 will feature some significant updates, including:
- **Rocksky Integration:** Rocksky is an AT Protocol music scrobbling platform. Integrating it with RaccNet Pocket means Rocksky user's can have a music listening history tab on their profile, as well as a realtime "Listing to:" status.
- **UI Refinements:** A more consistent and customizable UI language, allowing custom user-generated themes.
- **Profile Tab Overhaul:** Long-form, short-form, and image based tabs will be available on profile pages, each with their own unique layout.
- **Enhanced Feed Browsing:** The "Return to Feed" button in the Hub will be split into sperate "Timeline" and "Explore" buttons. Timeline will open the feed as normal, whereas Explore will open an overhauled Grid mode with unique layouts for viewing different types of media.
